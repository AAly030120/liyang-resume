## 这个仓库是什么
- 单文件 `index.html`（含样式与交互），可直接部署为静态站点
- 板块含「学习探索 / 项目经历 / 能力雷达」等；项目卡片点击可展开详情抽屉
- 内置「AI 岗位匹配器」：粘贴职位 JD 即可做简历匹配度分析（前端交互）

## 本地预览
```bash
git clone https://github.com/AAly030120/liyang-resume.git
# 直接用浏览器打开 index.html，或起一个本地服务：
python -m http.server 8000   # 访问 http://localhost:8000
```
